# market-analyzer — 다니엘스테이 단기임대 시장분석 CLI (v2)

수작업+에이전트로 하던 조사 파이프라인(33m2 공급·예약률 + MOLIT 실거래 + 정본 수익 산식)을
로컬 프로그램으로 만든 것. Python 표준 라이브러리 + `requests` 만 사용.

**v2 = 분석·판단 층 추가** — v1(수집·계산) 위에 "위치만 정하면 프로그램이 분석·추천까지":
- **판단룰 엔진(`rules.py`)**: 품질교락 감지·신뢰등급 A/B/C·타채널 해석·조건별 추천을
  결정적 룰로 코드화(정본 `plan_src/yield_deposit_bands.md`). 리포트에 "분석·추천" 섹션 자동 생성.
- **위치 자유 입력(`locate.py`)**: 사전에 없는 지역도 지역명만으로 좌표·법정동·LAWD 자동 결정
  (지오코딩→33m2 주소→LAWD→단지명 역매칭). 외부 API 키 불필요.
- **스캔 모드(`--scan`)**: 지역 전체를 타일 수집→그리디 500m 클러스터링→상위 N 클러스터
  각각 분석→비교 랭킹 리포트.

## 설치·실행

```bash
pip install requests
cd market-analyzer
# 한글 출력이 깨지면(cp949 콘솔) UTF-8 강제:
#   Windows PowerShell:  $env:PYTHONIOENCODING="utf-8"
#   bash:                PYTHONIOENCODING=utf-8 python analyzer.py ...
python analyzer.py --loc 동탄역 --radius 500
```

### v3 새 사용법 3줄
```bash
python analyzer.py --loc 동탄역 --session-file session.txt   # 단일 지역: 향후 8주 실측 선점률 + 보수 순수익
python analyzer.py --loc 상현역                              # 세션 없으면 공급·월세만(수익 계산 보류)
python analyzer.py --scan "수원시 영통구" --top 5 --occ 0.55  # 지역 스캔(스캔만 --occ 가정 허용)
```

### v3 분석 방식 (2026-07 개편)
- **선점률 = 실측 필수**: 33m2 캘린더에서 **향후 8주(측정일 기준)** 의
  `booking+disable ÷ 기간` = 통합 선점률.
  ⚠ **33m2 캘린더 API는 과거 날짜를 반환하지 않습니다**(2026-07 상현역 브라우저 세션 실측:
  6월 조회 0건, 7월은 오늘 이후만). 따라서 "지난 8주 확정 실적" 측정은 **불가능**하며
  `--window past` 는 API 미지원 에러로 차단됩니다. 향후 창은 **창 후반이 아직 예약으로
  채워지는 중**이라 **하한 성격**입니다(실제 최종 가동률 ≥ 측정된 선점률).
  세션이 없으면 수익 계산은 **"세션 필요"로 보류**하고 공급·월세만 출력(가정치 대체 없음).
- **매물별 선점률 랭킹**: 표본 매물 각각의 선점률을 계산해 **상위 5개를
  매물명·주소·주간가·선점률로 랭킹**(1위 강조) — "가장 잘 도는 지점" 식별용.
- **보수 순수익(기본 출력)**: `월 기대매출 = 주간가중위 × 4.345 × 실측 선점률`,
  `보수 순수익 = 기대매출 − 500밴드 월세중위 − 관리비` (다른 가감 없음, 관리비는 [가정] 표기,
  1000밴드는 참고 행). 기존 정본 산식(위탁 60/50%·청소·수수료)은 **"상세 모델" 보조 섹션**으로 유지.

## 웹 UI (브라우저에서 사용)

CLI를 브라우저 폼으로 감싼 로컬 웹 앱. 의존성 추가 없음(표준 라이브러리 `http.server`).

```bash
cd market-analyzer
python web.py          # http://localhost:8899
```

- **메인 화면**: 지역명 입력(등록역은 클릭 칩으로), 반경(기본 500m) 입력 후 **[분석 시작]**.
  최근 리포트 목록과 세션 상태 배지 표시.
- **결과 화면**: ① 실측 선점률(측정 창 명시) ② 선점률 최고 지점 랭킹(1위 강조)
  ③ 보수 순수익 계산표(기대매출→월세→관리비→순수익, 500밴드 기준) ④ 상세 모델(보조).
- **분석 실행**: 폼 제출 → 파이프라인 동기 실행(수십 초) → 완료 시 생성된 리포트로 이동.
  미등록 지역·수집 실패는 폼 상단에 읽을 수 있는 에러 메시지로 표시.
- **리포트 열람**: `output/`의 HTML 리포트를 `/report?f=<파일명>`으로 서빙(경로 탐색 차단).

Claude Code 미리보기로 띄우려면 `.claude/launch.json`의 `analyzer` 항목(포트 8899) 사용.

### 세션 자동 획득 (로그인만 하면 끝 — `session_auto.py`)
쿠키 수동 복사가 번거로우므로 **우선순위 3단 폴백**으로 세션을 자동 확보합니다.

1. **브라우저 쿠키 자동 추출 (기본)**: 평소 브라우저(Edge→Chrome 순)에서 33m2에
   로그인돼 있으면 **[분석 시작]만 눌러도** 프로그램이 로컬 쿠키 저장소에서 33m2 세션을
   자동으로 읽어 검증(`GET /v1/use-auth/user/me`) 후 사용. `browser_cookie3` 사용
   (`pip install browser_cookie3`). 최신 Edge/Chrome은 앱바운드 암호화로 관리자 권한이
   필요할 수 있으며, 실패 시 안전하게 건너뛰고 2단계로 폴백합니다.
2. **앱 내 로그인 (폴백)**: 메인 화면의 **"33m2 로그인"** 폼에 이메일/비밀번호 입력 →
   서버가 **브라우저와 동일한 Next.js 서버액션(`signIn`) 플로우**로 대신 로그인하고
   **세션 쿠키만** `session.txt` 에 저장. 🔒 **비밀번호는 저장·로깅하지 않습니다**
   (메모리에서만 사용, 화면에도 명시). 로그인 실패는 33m2 서버가 준 메시지를 그대로 표시.
   카카오·네이버·애플 등 **소셜 가입 계정은 이메일/비밀번호 로그인이 불가**하므로
   1단계(브라우저 세션 자동 감지)를 쓰라는 안내가 함께 표시됩니다.

   > 참고(리버스 결과): 로그인은 REST가 아니라 Next.js 서버액션이다.
   > `POST https://web.33m2.co.kr/ko` + 헤더 `Next-Action: 7f57b50f3c…`,
   > 바디 `[{"username","password","rememberMe"}]`. 비밀번호는 **클라이언트 암호화·해시 없음**
   > (HTTPS 평문), CSRF·캡차·공개키 선행요청 없음.
   > 직접 `POST /v1/user/login` 은 자격증명이 맞아도 항상 `VLD_002`("잘못된 요청입니다")를
   > 반환한다 — VLD_002는 자격증명 오류가 아니라 **요청 거부**이며, 실제 자격증명 오류는
   > `AUTH_001` 이다.
3. **쿠키 붙여넣기 (최후 수단)**: 로그인 카드의 **"고급 · 쿠키 직접 붙여넣기"** 접기 안에
   기존 textarea 유지(`Cookie: ...` 또는 `Bearer ...`).

#### 브라우저 로그인 → 세션 가져오기 (권장·가장 확실)
앱 내 로그인이 **`COMN_003` "처리중입니다"** 로 막힐 수 있습니다(계정별 로그인 처리 잠금
추정 — 웹 클라이언트 번들에 없는 백엔드 전용 코드라 재시도로 잘 풀리지 않음). 이때는:

- **웹 UI만으로 완결 (권장)**: **[전용 창으로 로그인]** 클릭 → 열린 전용 창에서 33m2 로그인 →
  **[세션 가져오기]** 클릭. 전용 창은 임시 프로필 + 원격 디버깅 포트(9222)로 뜨므로
  **기본 브라우저 프로필을 건드리지 않고 관리자 권한도 불필요**하며, CDP
  `Network.getAllCookies` 로 **httpOnly 쿠키까지** 읽어 `session.txt` 에 저장·검증합니다.
  세션 확보 후 전용 창은 닫아도 됩니다. (평소 브라우저에 이미 로그인돼 있다면
  [세션 다시 감지]만으로도 됨)
- 필요 패키지: `pip install websocket-client` (CDP 통신용).
- **터미널 헬퍼**(선택):
  ```bash
  python get_session.py            # 브라우저 열고 → 로그인 후 Enter → 쿠키 재추출
  python get_session.py --no-open  # 이미 로그인한 경우 감지만
  python get_session.py --profile  # 전용 프로필+원격 디버깅(관리자 권한 불필요)
  ```
  `--profile` 은 임시 프로필로 크롬/엣지를 띄우므로 **기본 브라우저 프로필을 건드리지 않고**
  앱바운드 암호화 권한 문제도 우회합니다(CDP로 쿠키 획득, `websocket-client` 설치 시).
- 최신 Edge/Chrome은 브라우저가 **실행 중이면** 쿠키를 못 읽을 수 있으니, 감지 실패 시
  브라우저를 완전히 종료하고 다시 시도하세요.

- **배지**: `세션 자동 감지됨(브라우저)` / `앱 로그인 세션` / `붙여넣은 세션` / `세션 없음 — 로그인 필요`.
- **만료 자동 복구**: 분석 중 세션 만료(401) 감지 시 브라우저 자동 추출을 **1회 재시도**한 뒤
  재조회. 그래도 실패하면 수익 계산만 보류(공급·월세는 정상 출력).
- **세션 지우기 / 로그아웃**: 세션이 있으면 카드에서 `세션 지우기`(session.txt·session.src 삭제).

> CLI에서는 자동 추출을 쓰지 않고 `--session-file session.txt` 로 세션을 직접 지정합니다
> (웹 UI에서 로그인해두면 같은 `session.txt` 를 CLI가 공유).

## 사용법

```
python analyzer.py --loc <지역> [옵션]          # 단일 지역
python analyzer.py --scan "<지역명>" [옵션]      # 스캔(클러스터 랭킹)
```

| 인자 | 기본 | 설명 |
|---|---|---|
| `--loc` | — | 지역명(사전·자동) 또는 수동지정 시 표시 이름 |
| `--scan` | — | 스캔 모드: 지역명(예: `"수원시 영통구"`) 타일수집→클러스터링→랭킹 |
| `--top` | 5 | 스캔 시 분석할 상위 클러스터 수 |
| `--min-cluster` | 3 | 스캔 클러스터 최소 매물 수 |
| `--radius` | 500 | 공급 스캔 반경(m) |
| `--months` | 6 | MOLIT 실거래 조회 개월 수(최근) |
| `--weeks` | 8 | 선점률 조사 창(주) |
| `--window` | future | 선점률 측정 창: `future`=향후 N주(기본·유일 지원). `past`는 33m2 API가 과거 날짜를 미반환해 **미지원**(에러) |
| `--samples` | 10 | 예약률 캘린더 표본 수(가격 중위권, 조회 상한·1초 스로틀) |
| `--mgmt` | 10 | 관리비 가정(만원, 보수 순수익에 [가정] 표기) |
| `--occ` | — | **스캔 모드 전용** 가정 예약률(0~1). 단일 지역 분석은 실측만 사용 |
| `--session-file` | — | 33m2 로그인 세션 파일(쿠키/Bearer) |
| `--no-cache` | off | MOLIT 월별 캐시 미사용(강제 재수집) |
| `--lat --lon --lawd --dong` | — | 사전·자동 모두 실패 시 수동 지정 |

### 위치 해석 3단계(우선순위)
1. **사전(빠른 경로, `stations.py`)**: 영통역 · 동탄역 · 상현역 · 정자역 · 서현역 · 오리역 ·
   수원역 · 평촌역 · 광교중앙역 · 원천동 · 상갈역 (좌표+LAWD+법정동 내장).
2. **자동 해석(`locate.py`)**: 사전에 없으면 지역명만으로 자동 —
   OSM Nominatim 지오코딩(키 불필요) → 반경 내 33m2 주소필드 최빈 시군구/법정동 →
   행안부 법정동코드(`.cache/lawd.csv`, 실패 시 경기남부 하드코딩 폴백)로 LAWD 매핑 →
   MOLIT 수집 후 **33m2 표본 단지명을 MOLIT 단지명에 역매칭**해 법정동 검증·대체
   (예: 동탄역 33m2 주소 최빈 '오산동'은 MOLIT ≤33㎡ 표본 0건 → 표본 단지가 실거래된 '여울동' 자동 대체).
   해석 근거는 리포트 방법론(섹션 0)에 자동 기재.
3. **수동 지정**: 위 둘이 모두 실패할 때만.
```bash
python analyzer.py --loc 새지역 --lat 37.30 --lon 127.10 --lawd 41590 --dong 반송동 능동
```

## 세션 파일 (예약률 조회, 선택)

33m2 예약 캘린더(`/v1/use-auth/rooms/{rid}/schedules?year=YYYY&month=M`)는
**로그인 세션**이 필요합니다. `year`/`month` 는 **필수 파라미터**이며, 빠지면
로그인 상태에서도 `400 VLD_001`("월은 필수입니다")로 거부됩니다 — 측정 창(향후 8주)이
걸치는 모든 달을 순회 호출해 날짜 단위로 병합합니다.
세션이 없으면 선점률 실측이 불가하므로 **수익 계산은 "세션 필요"로 보류**되고
공급·월세(MOLIT)까지만 출력됩니다(가정치 대체 없음).

세션 파일 만드는 법:
1. 브라우저에서 https://web.33m2.co.kr 에 **본인 계정으로 로그인**.
2. 개발자도구(F12) → Network 탭에서 `schedules` 또는 `use-auth` 요청 하나를 클릭.
3. Request Headers 에서 다음 중 있는 것을 복사해 `session.txt` 에 붙여넣기:
   - `Cookie: ...` 한 줄 전체, 그리고/또는
   - `Authorization: Bearer <JWT>` 한 줄.
4. 실행: `python analyzer.py --loc 동탄역 --session-file session.txt`

`session.txt` 예시(둘 중 하나 또는 둘 다):
```
Cookie: SESSION=abc123; other=xyz
Authorization: Bearer eyJhbGciOi...
```
`#` 로 시작하는 줄은 주석. `session.txt` 는 `.gitignore` 에 등록되어 커밋되지 않습니다.
세션 만료(401)나 파싱 실패 시에도 죽지 않고 예약률만 건너뜁니다.

## 출력물
- **콘솔 요약**: 컨설턴트 스타일 결론·조건별 수익률·**분석·추천(등급·교락·타채널)**·주의점
- `output/<지역>_<날짜>.md` / `.html` : 단일 지역 리포트(섹션 0 위치해석 · 5 분석·추천 포함)
- `output/scan_<지역>_<날짜>.md` / `.html` : 스캔 모드 클러스터 비교 랭킹 리포트
- HTML은 다니엘스테이 딥그린 디자인(`plan_src/tokens.css` 인라인)

## 분석·추천 (v2 판단룰 엔진, `rules.py`)
정본 `plan_src/yield_deposit_bands.md` 의 컨설팅 휴리스틱을 결정적 룰로 코드화. 리포트에 자동 삽입:
- **품질교락 감지**: 저가 밴드 비용표본이 (a) 단일 단지 ≥60% 지배 + (c) 상대 밴드 대비 유의 저가
  (+ (b) 면적 괴리 보강)면 "품질교락 의심" 경고·근거 생성 (예: 정자500 우정오피스텔 71% 지배).
- **신뢰등급 A/B/C**: A=비용표본 ≥30·매출 ≥5·교락 없음 / C=비용 <10 또는 교락 또는 매출 <5 / B=중간.
- **타채널 해석**: 타채널비중 ≥15p→"멀티채널 운영 전제", ≤5p→"단일 채널로도 실현", ≥25p→"극단(필수)".
- **추천 생성**: 계산 가능한 밴드 셀 수익률순 → 1순위/조건부/부적합 + 근거·리스크 1줄,
  "수익률 극대화=500 / 현금 극대화=1000" 원칙 코멘트.
- **자기검증**: 모듈 로드 시 정본 사례(정자500 교락→C, 동탄 교락없음→A, 타채널 +2.7/16.8/25.0p)로
  룰 드리프트 방지(실패 시 즉시 중단). `python rules.py` 로 확인.

## 방법론 요약 (정본)
- **공급 필터(상시 지침)**: 33m2 오피스텔 유형만, 고시원·모텔·호텔·게스트하우스·쉐어·펜션 제외,
  원룸만(이름 키워드로 투룸/N베드/N인 제외). 요청 간 1초 스로틀.
- **위치 자동 해석**: 지오코딩(Nominatim, 키 불필요) → 33m2 주소 최빈 법정동 → LAWD 매핑 →
  단지명 역매칭 검증·대체(사전에 없는 지역도 이름만으로). 근거를 리포트에 기재.
- **스캔 모드**: Nominatim 바운딩박스 → 타일 전수 수집(rid 중복 제거) → 그리디 500m 클러스터링
  (이웃 최다 지점 중심, 매물 3+) → 상위 N 클러스터 법정동 자동 결정·비용·(세션 시 표본 5개 예약률)
  → 수익률순 비교 랭킹. 세션 없으면 공급·비용 랭킹(+`--occ` 가정 시 수익률).
- **선점률**: 통합 선점률(booking+disable, 향후 8주) 기본 + 33m2 단독(booking) · 타채널비중 병기.
- **실거래 월세**: MOLIT 오피스텔 전월세 최근 N개월 → 전용 ≤33㎡·월세건·해당 법정동 →
  보증금 밴드 분리(500=300~700만 / 1000=700초과~1300만, **환산 금지**). 표본<3 밴드는 "표본 부족".
  월별 결과는 `.cache/` 에 저장해 재실행 시 재사용.
- **수익률(정본 산식, `model.py`)**:
  `순익 = share × [주간가중위×4.345×예약률×0.967 + 3만×4.345×예약률 − 3.2만 − (밴드월세+관리비+공과금6만)]`
  share 60%/50% 병기, 연 수익률 = 순익×12÷보증금(500/1000).
  **모듈 로드 시 앵커 자기검증**(영통 33만·69.1%·all-in 60만·공과금 미가산 → 24.97만 ±0.1),
  실패 시 즉시 중단(산식 변형 사고 방지).

## 모듈 구성
| 파일 | 역할 |
|---|---|
| `analyzer.py` | 메인 CLI(파이프라인 오케스트레이션 · 단일/스캔 분기) |
| `m33.py` | 33m2 공급 스캔(지도) + 예약률(캘린더) |
| `molit.py` | MOLIT 실거래 수집·밴드 집계(캐시) |
| `model.py` | 정본 수익 산식 + 앵커 자기검증 |
| `rules.py` | **(v2)** 판단룰 엔진(품질교락·신뢰등급·타채널·추천) + 룰 자기검증 |
| `locate.py` | **(v2)** 지역명 자유 입력 → 좌표·법정동·LAWD 자동 해석(키 불필요) |
| `scan.py` | **(v2)** 스캔 모드(타일 수집·그리디 클러스터링·클러스터별 분석) |
| `report.py` | 콘솔 + md + HTML 리포트(단일 + 스캔 랭킹) |
| `stations.py` | 역/지역 사전(좌표+LAWD+법정동, 빠른 경로) |
| `config.py` | 경로·상수 |

MOLIT 서비스키는 `plan_src/molit.key` 를 그대로 읽습니다(별도 설정 불필요, `.gitignore` 등록됨).

# 단위 검증
