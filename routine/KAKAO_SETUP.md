# 카카오톡 알림 연동 — 최초 1회 준비 안내

루틴(3일마다 도는 경기남부 시 스캔)이 끝나면 **결과 요약과 보고서 이미지를 카카오톡 "나에게 보내기"로** 자동 전송합니다.
아래 준비는 **처음 한 번만** 하면 됩니다. 소요 시간 약 5~10분.

- 보내는 내용: **텍스트 요약 1건 + 보고서 본문 이미지 2장**(1/2 지도·요약, 2/2 전 매물 가동률).
- 받는 사람: **본인(나에게 보내기)**. 다른 사람에게는 전송되지 않습니다.

---

## 카톡으로 보낼 수 있는 것 / 없는 것

| | 카톡 전송 | 비고 |
|---|---|---|
| 텍스트 요약 | 가능 | 200자 상한(초과분 자동 말줄임) |
| 링크(URL) | 가능 | 로컬 경로는 넣지 않습니다 |
| 이미지(JPG·PNG) | 가능 | 업로드 후 URL로 참조. 세로로 아주 긴 이미지도 됩니다(2995px 발송 확인) |
| **PDF·HTML·ZIP 등 파일 첨부** | **불가** | **카카오 API가 지원하지 않습니다.** 우회 방법이 없습니다 |

> 그래서 보고서는 **JPG로 렌더링해서** 보냅니다.
> PDF·HTML 원본과 **표지 이미지**는 PC(`routine\out\`)에만 저장되고 카톡으로는 나가지 않습니다.

---

## 준비물

- 카카오 계정 (평소 쓰시는 카카오톡 계정)
- 이 PC의 웹 브라우저

---

## 1단계 — 카카오 개발자 사이트에서 애플리케이션 추가

1. 브라우저에서 <https://developers.kakao.com> 접속 → 우측 상단 **로그인** (평소 카카오 계정).
2. 상단 메뉴 **내 애플리케이션** 클릭.
3. **애플리케이션 추가하기** 버튼 클릭.
4. 입력 칸 3개를 채웁니다. 내용은 자유롭게 정하셔도 됩니다.
   - 앱 이름: `다니엘스테이 알림`
   - 회사명: `다니엘스테이`
   - 카테고리: 아무거나 (예: 비즈니스)
5. 약관 동의 체크 → **저장**. 목록에 방금 만든 앱이 보이면 클릭해서 들어갑니다.

## 2단계 — Web 플랫폼 등록

1. 왼쪽 메뉴에서 **앱 설정 > 플랫폼** 클릭.
2. 화면의 **Web** 영역에서 **Web 플랫폼 등록** 버튼 클릭.
3. 사이트 도메인 칸에 아래를 **그대로** 입력하고 저장합니다.

   ```
   http://localhost:8950
   ```

   (뒤에 슬래시(/)를 붙이지 마세요.)

## 3단계 — 카카오 로그인 활성화 + Redirect URI 등록

1. 왼쪽 메뉴 **제품 설정 > 카카오 로그인** 클릭.
2. 맨 위 **활성화 설정** 스위치를 **ON** 으로 켭니다. (확인 창이 뜨면 확인)
3. 같은 화면 아래쪽 **Redirect URI** 항목의 **등록** 버튼 클릭 → 아래를 **그대로** 입력하고 저장.

   ```
   http://localhost:8950/callback
   ```

   (`/callback` 까지 반드시 포함해야 합니다. 이게 틀리면 나중에 `KOE006` 오류가 납니다.)

## 4단계 — 동의항목에서 "카카오톡 메시지 전송" 켜기

1. 왼쪽 메뉴 **제품 설정 > 카카오 로그인 > 동의항목** 클릭.
2. 목록을 아래로 내려 **접근권한** 영역의 **카카오톡 메시지 전송** (영문 ID: `talk_message`) 행을 찾습니다.
3. 오른쪽 **설정** 버튼 클릭 → **이용 중 동의** 선택.
4. 동의 목적 칸에 이유를 한 줄 적습니다. 예: `시장조사 리포트 완료 알림을 본인에게 전송`
5. **저장**. 상태가 "이용 중 동의"로 바뀐 걸 확인합니다.

> 이 항목이 꺼져 있으면 발송 시 `code -402 (권한 없음)` 오류가 납니다.

## 5단계 — REST API 키 복사

1. 왼쪽 메뉴 **앱 설정 > 앱 키** 클릭.
2. 표에서 **REST API 키** 한 줄을 찾아 값을 복사합니다.
   - 네이티브 앱 키·JavaScript 키·Admin 키가 **아닙니다.** 반드시 **REST API 키**.
   - 영문+숫자 32자 정도의 문자열입니다.

## 6단계 — 토큰 발급 실행

1. PC에서 명령 프롬프트(또는 PowerShell)를 열고 프로젝트 폴더로 이동합니다.

   ```
   cd C:\Users\User\test
   python routine\kakao_setup.py
   ```

2. `카카오 REST API 키를 붙여넣고 Enter:` 가 뜨면 5단계에서 복사한 키를 붙여넣고 Enter.
   (또는 한 줄로: `python routine\kakao_setup.py --key 여기에키`)
3. 브라우저가 자동으로 열립니다 → **카카오 로그인** → **동의하고 계속하기**.
4. 브라우저에 "카카오 연동이 완료되었습니다" 화면이 뜨면 끝. 창을 닫으셔도 됩니다.
5. 명령창에 `완료: 카카오 토큰을 저장했습니다.` 가 보이면 성공입니다.

### `invalid_client (Bad client credentials)` 가 뜬다면

앱에 **클라이언트 시크릿**이 켜져 있는 경우입니다.
카카오 콘솔에서 **앱 > 플랫폼 키 > REST API 키 > 클라이언트 시크릿** 값을 복사한 뒤,
`--secret` 을 붙여 6단계를 다시 실행하세요.

```
python routine\kakao_setup.py --key 여기에키 --secret 여기에시크릿
```

시크릿은 REST 키와 함께 `routine/kakao_token.json` 에 저장되어, 이후 자동 갱신에도 그대로 쓰입니다.
(시크릿을 안 쓰는 앱이라면 `--secret` 없이 그대로 두시면 됩니다.)

### 잘 됐는지 확인

```
python routine\kakao_notify.py --text "연동 테스트"
```

본인 카카오톡의 "나와의 채팅"에 메시지가 도착하면 정상입니다.

이미지까지 확인하려면:

```
python routine\kakao_notify.py --text "연동 테스트" --image routine\out\어떤보고서_1.jpg
```

### 이미지 보내기 옵션

| 옵션 | 설명 |
|---|---|
| `--image <경로>` | 보낼 이미지. **여러 번 쓰면 쓴 순서대로** 발송합니다 |
| `--image-title <제목>` | `--image` 와 **순서대로 짝**지어집니다. 생략하면 파일명이 제목이 됩니다 |
| `--image-desc <설명>` | 마찬가지로 순서대로 짝지어집니다. 생략하면 비워둡니다 |

```
python routine\kakao_notify.py --text "수원시 스캔 완료" ^
  --image routine\out\리포트_1.jpg --image-title "1/2 지도·요약" ^
  --image routine\out\리포트_2.jpg --image-title "2/2 전 매물 가동률"
```

- 요약 텍스트를 먼저 보내고, 이어서 이미지를 **1초 간격**으로 순서대로 보냅니다.
- 한 장이 실패해도 나머지는 계속 보내고, 마지막에 `발송 N건 성공 / M건 실패` 로 집계해 알려줍니다.
- 5MB가 넘는 이미지는 자동으로 폭·품질을 줄여 올립니다(**원본 파일은 그대로 보존**).

## 토큰 만료 주의

| 항목 | 유효기간 | 자동 처리 |
|---|---|---|
| access token | 약 **6시간** | 만료되면 프로그램이 **자동 갱신**합니다. 신경 쓰실 것 없습니다. |
| refresh token | 약 **2개월** | 자동 갱신 불가. **만료되면 6단계를 다시 실행**해야 합니다. |

- 루틴이 3일마다 돌기 때문에 평소에는 refresh token이 계속 살아 있습니다.
- 다만 **2개월 이상 루틴을 한 번도 돌리지 않으면** refresh token이 만료됩니다.
  이때는 `python routine\kakao_setup.py` 를 다시 실행해 재인증하면 됩니다(1~5단계는 다시 안 해도 됩니다).
- 카톡 알림이 안 오면 먼저 `python routine\kakao_notify.py --text "테스트"` 를 돌려 메시지를 확인하세요.

## 보안

- 발급된 토큰은 `routine/kakao_token.json` 에만 저장되며, 화면·로그에는 앞 4자만 표시됩니다.
- 이 파일은 비밀번호와 같습니다. **깃 커밋·메일·메신저로 공유하지 마세요.** (`.gitignore`에 등록되어 있습니다.)
- 유출이 의심되면 developers.kakao.com에서 앱을 삭제하거나 키를 재발급한 뒤 6단계를 다시 실행하세요.

## 자주 나는 오류

| 메시지 | 원인 | 해결 |
|---|---|---|
| `KOE006` | Redirect URI 불일치 | 3단계의 `http://localhost:8950/callback` 을 정확히 등록했는지 확인 |
| `KOE101` | REST API 키 오류 | 5단계에서 **REST API 키**를 복사했는지 확인 |
| `code -402` | talk_message 동의 누락 | 4단계를 다시 수행하고 6단계 재실행 |
| `code -401` | 토큰 만료·폐기 | 6단계 재실행 |
| `포트를 열 수 없습니다` | 8950 포트 사용 중 | 잠시 후 재시도 (또는 `--port 8951` 로 실행하고 2·3단계 URL의 포트도 함께 변경) |
| `토큰 파일이 없습니다` | 아직 setup 미실행 | 6단계 실행 |
