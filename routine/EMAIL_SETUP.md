# 이메일 발송 설정 (PDF 첨부용)

보고서 PDF를 메일로 받으려면 **한 번만** 아래 설정을 해두면 됩니다.
이후에는 루틴이 알아서 보고서를 첨부해 메일을 보냅니다.

> **왜 이렇게 하나요?**
> 카카오톡은 파일 첨부를 지원하지 않고, AI가 메일 커넥터로 첨부를 보내는 것도
> 실제로 불가능합니다(파일 내용을 글자로 옮겨 적어야 하는데 20만 자를 정확히
> 재현할 수 없습니다 — 실제로 시도해 2,000자 지점부터 어긋나는 것을 확인했습니다).
> 그래서 컴퓨터에 있는 스크립트가 **파일을 디스크에서 직접 읽어** 보냅니다.

---

## ⚠️ 먼저 읽어주세요 — 앱 비밀번호 취급 원칙

- 앱 비밀번호는 **누구에게도 알려주지 마세요. 작업을 돕는 AI(저 포함)도 예외가 아닙니다.**
- 채팅창·메모·메신저에 붙여넣지 마세요. **아래 4단계에서 설정 파일에만** 입력합니다.
- 설정 파일 `routine/email_config.json` 은 `.gitignore` 에 등록되어 있어 GitHub에 올라가지 않습니다.
- 스크립트는 이 값을 SMTP 로그인에만 쓰고, 화면·로그·에러 메시지 어디에도 출력하지 않습니다.
- 혹시 유출된 것 같으면 myaccount.google.com/apppasswords 에서 해당 항목을 삭제하면 즉시 무효화됩니다.

---

## 1단계 — 2단계 인증 켜기

1. https://myaccount.google.com/security 접속
2. **"Google에 로그인"** 항목에서 **2단계 인증** 클릭
3. 안내를 따라 켭니다(휴대폰 번호 인증). **이미 켜져 있으면 그냥 넘어가세요.**

> 2단계 인증이 꺼져 있으면 다음 단계의 앱 비밀번호 메뉴 자체가 보이지 않습니다.

## 2단계 — 앱 비밀번호 발급

1. https://myaccount.google.com/apppasswords 접속 (비밀번호 재확인을 요구할 수 있습니다)
2. 앱 이름에 **`다니엘스테이 루틴`** 입력
3. **만들기** 클릭 → **16자리 비밀번호**가 나옵니다 (예: `abcd efgh ijkl mnop` 처럼 4자씩 띄어서 표시)
4. 이 창은 **한 번만** 보여줍니다. 창을 닫기 전에 4단계까지 끝내세요.
   (닫아버렸으면 그냥 삭제하고 새로 발급하면 됩니다.)

## 3단계 — 설정 파일 만들기

명령 프롬프트(또는 PowerShell)에서:

```
cd C:\Users\User\test
python routine\email_send.py --init
```

`routine\email_config.json` 파일이 만들어집니다. 메모장으로 엽니다:

```
notepad routine\email_config.json
```

## 4단계 — 내 정보 채우기

파일 내용에서 **3군데**만 고칩니다.

```json
{
  "smtp_host": "smtp.gmail.com",
  "smtp_port": 465,
  "use_ssl": true,
  "username": "본인지메일@gmail.com",        ← ① 본인 지메일 주소
  "app_password": "abcdefghijklmnop",       ← ② 2단계에서 받은 16자리 (공백 다 빼고 붙여서)
  "from_name": "다니엘스테이",
  "to": ["본인지메일@gmail.com"]              ← ③ 받을 주소 (여러 명이면 쉼표로 나열)
}
```

- **공백은 반드시 빼주세요.** `abcd efgh ijkl mnop` → `abcdefghijklmnop`
  (실수로 띄어 써도 스크립트가 알아서 지웁니다.)
- 큰따옴표 `"` 는 지우지 마세요.
- 여러 명에게 보내려면: `"to": ["나@gmail.com", "직원@gmail.com"]`

저장하고 닫습니다.

## 5단계 — 로그인 확인 (메일은 안 보냅니다)

```
python routine\email_send.py --test
```

- **성공**: `로그인 성공 — smtp.gmail.com:465 (SSL) ...` 이 나옵니다. 끝났습니다.
- **`535` 오류**: 앱 비밀번호가 틀렸거나 2단계 인증이 꺼져 있습니다. 2단계를 다시 하세요.
- **`설정 파일이 없습니다`**: 3단계를 안 했거나 다른 폴더에서 실행했습니다. `cd C:\Users\User\test` 부터 다시.

## 6단계 — 실제 발송 테스트

```
python routine\email_send.py --subject "테스트" --body "본문" --attach routine\out\수원시_영통역_요약.pdf
```

메일함에 PDF가 첨부된 메일이 도착하면 완료입니다.
(스팸함에 들어갔는지도 한 번 확인해보세요. 처음 한 번만 그럴 수 있습니다.)

## 이후 사용법

설정이 끝나면 3일마다 도는 시장조사 루틴이 보고서를 만들 때 **자동으로 메일을 보냅니다.**
설정을 안 해두면 메일만 조용히 건너뛰고 나머지(카톡 알림·보고서 생성)는 그대로 진행됩니다.

수동으로 아무 파일이나 보내고 싶을 때:

```
cd C:\Users\User\test
python routine\email_send.py --subject "제목" --body "본문 내용" ^
  --attach routine\out\다니엘스테이_수원시_영통역_2026-08-21.pdf ^
  --attach routine\out\다니엘스테이_수원시_영통역_2026-08-21.jpg
```

| 옵션 | 설명 |
|---|---|
| `--subject` | 제목 (한글 가능) |
| `--body` | 본문 (한글 가능) |
| `--attach` | 첨부 파일. 여러 개면 `--attach` 를 여러 번 씁니다. 한글 파일명 OK |
| `--to` | 이번 메일만 다른 주소로 보낼 때 |
| `--init` | 설정 템플릿 생성 (기존 파일은 덮어쓰지 않음) |
| `--test` | 설정·로그인만 확인, 발송 안 함 |

## 문제가 생겼을 때

| 증상 | 원인 / 해결 |
|---|---|
| `설정 파일이 없습니다` | `--init` 을 아직 안 했습니다. 3단계부터 다시. |
| `앱 비밀번호가 아직 입력되지 않았습니다` | 4단계에서 `app_password` 를 안 채웠습니다. |
| `535 ... 2단계 인증` | 앱 비밀번호가 틀렸습니다. 계정 비밀번호가 아니라 **앱 비밀번호 16자리**여야 합니다. 새로 발급받아 다시 넣으세요. |
| `첨부 파일을 찾을 수 없습니다` | 경로 오타이거나 `C:\Users\User\test` 가 아닌 폴더에서 실행했습니다. |
| `첨부 총 용량이 한도를 넘었습니다` | 지메일 한도 25MB 초과. 파일을 나눠서 두 번 보내세요. |
| `네트워크 오류` | 인터넷 연결 또는 방화벽이 465 포트를 막고 있습니다. 회사망이면 `use_ssl` 을 `false`, `smtp_port` 를 `587` 로 바꿔보세요. |
| 메일이 안 보임 | 스팸함을 확인하세요. |

## 지메일이 아닌 경우

`email_config.json` 의 `smtp_host` / `smtp_port` / `use_ssl` 만 바꾸면 됩니다.

| 서비스 | smtp_host | smtp_port | use_ssl |
|---|---|---|---|
| Gmail | `smtp.gmail.com` | 465 | `true` |
| 네이버 | `smtp.naver.com` | 465 | `true` |
| 다음/한메일 | `smtp.daum.net` | 465 | `true` |
| Outlook | `smtp-mail.outlook.com` | 587 | `false` (STARTTLS) |

네이버·다음도 계정 설정에서 **SMTP 사용**을 먼저 켜야 합니다.
